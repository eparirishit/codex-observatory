KNOW WHAT YOU ARE SEEING

Measured, inferred, or unavailable?

The dashboard labels its evidence so you can make decisions without mistaking token activity for subscription charges.

Measured

Recorded token counters, models, executions, explicit failures, compaction checkpoints, and account-limit snapshots.

Derived or inferred

Cache share is arithmetic. Context size is approximated by response input. Repeated arguments identify retry candidates, including intentional polling.

Unavailable

Exact quota spent per session, tool token prices, plugin instruction overhead, and platform activity absent from local logs.

Your token counts and subscription allowance are separate measurements. Cached input is included in input; reasoning is included in output. Account snapshots may include other chats and cloud work. Exact quota consumed by each session is unavailable.

Coverage & privacy

The reader opens session logs and selected configuration fields read-only. Prompts, reasoning text, commands, arguments, outputs, file paths, account IDs, credentials, and environment variables are excluded. No database, analytics, external assets, API calls, or browser storage. Exports contain anonymous IDs, timestamps, model/tool names, and counts.

How measurements are calculated

Response records are preferred and deduplicated by response ID. Token-count snapshots are not added again. Older logs use cumulative deltas, which can combine several responses and cannot always attribute a turn precisely. An inherited first snapshot is shown as an excluded baseline. Missing values appear as —, never zero.

Reasoning and cached input are subsets; do not add them twice. Session totals cover the records present in the logs. Segments with the same session ID are combined. Response IDs are deduplicated. Parent and child sessions are separate; parent totals do not automatically include children.

Compaction counts use committed compacted events. Imported compaction response items are not counted a second time. Log formats may change; coverage warnings identify unsupported or partial data.

Subscription quota conversion, per-tool token costs, per-plugin prompt overhead, and hidden platform work remain unavailable. No token-to-quota estimates are invented.
